# E2E 遗留问题修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修完 E2E 报告里的 10 类缺陷（移动菜单、aria-current、标题层级、矩阵状态、320px 溢出、404 canonical、图片 sizes、外链 rel、折行、内链整页刷新），并新增 `npm run check:dist` 把这些规则钉在构建产物上。

**Architecture:** 先写一个解析 `dist/` 的门禁脚本当「失败的测试」（任务 1），再用纯函数 + 单测修可测的行为（任务 2–4），然后改标题元素与样式选择器（任务 5–6），最后处理外链属性与 wouter 内链（任务 7），任务 8 跑全量门禁并复跑 E2E。

**Tech Stack:** React 19 + styled-components 6 + wouter + webpack 5 + node:test（Node 24 原生 TS 剥离）+ 手写 HTML 正则解析。

**Spec:** `docs/superpowers/specs/2026-11-03-e2e-fixes-design.md`

## Global Constraints

- 视觉零变化：标题层级调整只换元素，样式选择器跟着换（`& h4` → `& h3` 等），不改字号/颜色/间距。
- 只用 `index.html` 已有令牌，不新增色值、keyframes、视口媒体查询。
- 新代码不得出现 `window` / `matchMedia` / `document` 分支；SSR 与 CSR 输出逐字一致。
- 测试只能 import 不依赖 webpack 的模块（`import.meta.webpackContext`、`virtual:*` 在 Node 里不可用）。
- **不提交**：工作区有伙伴未提交的 23 个改动，本轮只写文件，提交由伙伴统一做。
- 门禁顺序：`npx tsc -b` → `npm run lint` → `npm test` → `npm run build` → `npm run check:dist`。

## Review Focus

1. **`/about` `/contact` `/responsibility` 的卡片标题升 h2 后的字号**：`cardCss` 的 `& h4 { font-size: 1.15rem }` 若不跟着改成 `& h2`，标题会变成 `Section` 的 `clamp(1.8rem, 2.8vw, 2.4rem)` —— 视觉回归。
2. **`/press/` 卡片**：`PressCard` 拆成 Link/Anchor 后，外链仍要 `target="_blank" rel="noopener noreferrer"`，内链不能有 `target`。
3. **页脚栏目名**改成 `span` 后，`text-transform: uppercase` 与字距必须逐字保留（`& h4` 整块搬进 `FooterColTitle`）。
4. **`sizes` 生成值**在 `intrinsicWidth < 860` 时必须用图片自己的宽度，否则 499px 的图会按 860px 拉候选。
5. **`aria-current` 在预渲染 HTML 里就要有**（SSR 通过 `Router hook={() => [url, ...]}` 注入路径），不能只靠客户端。

### Task 1: `check:dist` 门禁脚本（先让它红）

**Files:**

- Test: 本任务只引入脚本；`node scripts/check-dist.mjs` 的失败清单就是测试输出。

**Interfaces:**
- Produces: `node scripts/check-dist.mjs` 退出码 0 = 全部通过，1 = 有失败；每个失败一行 `✗ <文件>: <原因>`。

断言清单（每条都要实现）：
- `dist/` 不存在 → 提示先 `npm run build`，退出 1。
- 页面集 = `dist/**/index.html` + `dist/404.html`。
- 非 404 页面：`<h1>` 恰好 1 个。
- 标题序列（去掉 `<footer>…</footer>` 后按文档顺序扫 `<h[1-6]`）相邻层级差 ≤ 1。
- `<footer>` 内不得出现 `<h1>`–`<h6>`。
- 含 `<header>` 的页面（除 404）：`aria-current="page"` 恰好 1 处；404 允许 0。
- HTML 不含 `sizes="auto`。
- 每个 `<img ...>` 都有 `alt` 属性。
- 每个 `<a ... target="_blank">` 的 `rel` 含 `noopener`。
- 非 404：`<link rel="canonical">` 存在且等于 `站点源 + 页面路径`；404：无 canonical，且 `<meta name="robots" content="noindex">` 存在。
- 站点源从 `dist/sitemap.xml` 的第一个 `<loc>` 解析，不写死域名。

- [ ] **Step 1: 写脚本**

解析用正则（`/<h([1-6])\b[^>]*>/g`、`/<footer[\s\S]*?<\/footer>/g` 等），不引第三方解析器。失败计数 > 0 时 `process.exitCode = 1`。
